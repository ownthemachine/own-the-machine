# Licensing

Decided before the first public commit, because retrofitting licences is painful.

| What | Licence | Why |
|---|---|---|
| Legal text, recitals, memorandum | **CC BY-SA 4.0** | A fork that improves the law must stay open |
| Site and platform code (own-the-machine-site) | **AGPL-3.0** | A hosted fork stays open too |
| Review machinery (own-the-machine-tools) | **MIT** | Reuse for other legislation welcome |
| Simulator widget (embeddable) | **MIT** | Spread beats copyleft for the one viral component |
| Data: parameters, evidence tables | **CC0** (citation requested) | Zero friction for academics |
